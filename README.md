# PPSSPP4Wii
an ai assisted project, that probably is the first psp emulator for the wii, assisted by ppsspp for the HLE and groundwork and chatgpt 6.1 sol for most of the coding. IMPORTANT DISCLAIMER: iso's + cso's should be put inside USB:/Disks or SD:/Disks. credits to PPSSPP developers/contributors for the groundwork, ai for most of the code, and geoticraft-cyber as the lead developer.

Games Currently working: Terraria PSP by XD (homebrew) roughly 3.0fps at stock settings, graphical issue: on startup, text singleplayer and exit which are supposed to be yellow, are pink for some reason. GTA VCS: roughly 1.0fps displayed by performancd overlay but far slower speed observed in real time gameplay, no graphical issues. LBP: fps/speed forgot, runs but is extremely slow tho alot faster than VCS. no graphical issues, takes roughly 50 minutes to get in game for the intro. GOW ghost of sparta PAL: reaches language menu. graphical glitches at start, but they go away, seems to be because the wii is lagging so hard, it needs time to display it correctly. i got bored because it was too slow, therefore i dont know if it can reach gameplay.
it uses an intepreter (has a superinstruction!), and mostly software video emulation. but, there is GX Acceleration avaiable.
