# PPSSPP4Wii
(NOTICE: THIS PROJECT IS ABANDONED. IT GOT TOO TIME CONSUMING FOR JUST LITTLE FPS GAINS. FEEL FREE TO FORK IT) ppsspp4wii is a ai assisted project, that probably is the first psp emulator for the wii, assisted by ppsspp for the HLE and groundwork and chatgpt 6.1 sol for most of the coding. IMPORTANT DISCLAIMER: iso's + cso's should be put inside USB:/Disks or SD:/Disks. credits to PPSSPP developers/contributors for the groundwork, ai for most of the code, and geoticraft-cyber as the lead developer.
